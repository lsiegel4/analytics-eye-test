# Analytics Eye Test

College basketball scouting platform for NBA draft-eligible prospects. Advanced statistical profiles paired with curated YouTube clips organized by skill category.

## Project Structure

| Directory | Description |
|-----------|-------------|
| `web/` | Next.js 15 web application (Vercel deployment) |
| `pipeline/` | Python data pipeline (GitHub Actions) |
| `.github/workflows/` | CI/CD workflow definitions |
